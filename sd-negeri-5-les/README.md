# SD Negeri 5 Les

Website statis resmi SD Negeri 5 Les.

## Cara membuka

Buka file `index.html` langsung di browser.

## Struktur

- `index.html` - halaman utama website
- `style.css` - tampilan website
- `script.js` - menu mobile dan pencarian berita sederhana
- `logo.png` - logo sekolah

## Upload ke GitHub

Upload seluruh isi folder `sd-negeri-5-les` ke repository GitHub atau GitHub Pages.
